# Gemini Notebook, formerly NotebookLM (notebook.google.com)

Verified 2026-10-08 on a localized UI; the English labels below are unverified translations of the labels seen; the profile's UI labels hold the user's own. UIs change, so if a selector fails fall back to `find` plus a 0.3-scale screenshot. Snippets, LAST and the loop: workers/common.md.

- Data terms: not used for training unless feedback is sent, and feedback lets humans review the whole interaction, so never click thumbs up/down or send feedback.
- notebooklm.google.com redirects to notebook.google.com, titled "Gemini Notebook". New notebook: the "New notebook" button; it opens the add-source dialog (the URL ends in ?addSource=true). Every notebook is saved and auto-titled (/notebook/<id>); there is no temporary mode, so report it as a leftover. The run tag goes on the first line of the question.
- Add a pasted source: in the dialog click "Copied text", fill its source textarea (selected by placeholder) with snippet F (the value setter left the Insert button disabled), then click "Insert". Another textarea in the dialog searches the web for new sources: always target textareas by placeholder. File upload, Drive, websites and YouTube sources are offered but untested.
- Composer: the chat textarea, selected by its placeholder. Insert with snippet F.
- Send: find the chat composer's send button (arrow icon) and left_click it; matching the send label alone is ambiguous because the add-source dialog has one too.
- Last answer: LAST in common.md 6. It starts with a collapsed "Thoughts" header (never expanded), citation numbers sit on their own lines, and the end line came as " ALL DONE" with a leading space (snippet D and the parser handle all three).
- Mode: none seen; no Stop control seen.
- Meter: an in-app notice said usage limits reset every 5 hours (unverified; limits.md); source and query caps not checked.
- Phrasing: it answers only from its sources, so say what to write when they are silent (for example NOT IN SOURCES). Not for strict CSV (citation markers).
