# Microsoft Copilot (copilot.microsoft.com)

Added 2026-10-09 and NOT live-tested yet: the selectors below are placeholders for the first "test" run (modes/test.md) to confirm. Until then find the composer, send button and last answer with `find` plus a 0.3-scale screenshot, and use Relay mode (common.md 9) if that fails. Snippets, LAST and the loop: workers/common.md.

- Account: a personal Microsoft account only. If sign-in leads to an organization's page (a company logo, "Sign in with your organizational account", an ADFS or Entra page, a work or school address), stop for that site: never run delegated work on an employer's or school's account, whose data rules and monitoring apply, and never type a password. Seen 2026-10-09: on one account the site redirected straight to an employer's sign-in page because Chrome held a work session; the user must sign in to Copilot with a personal account first.
- Models: Copilot has run OpenAI GPT models alongside Microsoft's own (2025-26), so for cross-model checks count it as the same family as ChatGPT (qc.md 4).
- Data: depending on the account's privacy settings, consumer Copilot may use conversations to improve Microsoft's products. No personal data unless the user names Copilot for it (SKILL.md 2.5).
- New chat: https://copilot.microsoft.com/ . Chats should be saved in history; log the URL the tab shows after sending (to confirm on the first test). Use no private or temporary mode if one appears.
- Composer, send, last answer, stop control: to be established by the first test; then record them here and in common.md 6.
- Tier: free (Tier 2) unless the profile lists Copilot Pro or a Microsoft 365 plan with Copilot (Tier 1).
- Meter: no published consumer cap found (unverified); careful mode applies (SKILL.md 2.9).
